00 事件 — AIペネトレーション — 国家支援アクターがAI自律ペネトレーションOSSを実戦使用した事件

3行で分かる

  1. 中国支援の攻撃グループ Storm-0940 が、AIが自律的にペネトレーションを進めるOSS「ARTEX」を実戦使用したと Microsoft が 2026-10-21 に公式報告した（本ガイドは攻撃手順を扱わない）
  2. 国家支援級の攻撃者が「AIに攻撃をやらせる」時代になった
  3. 本ガイドは事件を防御側から読み解き、個人開発者のアプリへの適用実録（IDOR発見と修正）までを示す

何が起きたか（事実の整理）

2026-10-21、Microsoft Security Blog が次の事実を公式報告した。

項目 事実
攻撃者 中国国家支援の攻撃グループ Storm-0940
使われたツール AI自律ペネトレーションOSS「ARTEX」（Autumn-27 作・Go + Next.js・AGPL-3.0）
侵入起点 ConnectWise（リモート管理ソフト）のサプライチェーン侵害
規模 2,250 テナント超へのサインイン試行・パスワードスプレー 15.1 万件超
ARTEX の現在 元リポジトリは削除/非公開（GitHub API で 404 を実測確認済み・英語翻訳のフォーク群のみ残存）

出典:

  • Microsoft Security Blog — Storm-0940 uses ARTEX agentic AI in ConnectWise supply chain compromise
  • 防御側資料: jiwoochris/artex-global の Defense & Detection Guide（ARTEX 作者と無関係な第三者が公開する検知・ハードニング資料）

何が新しいのか

「AIに攻撃をさせる」こと自体は以前からありました。今回の報告の重みは別のところにあります。

  1. 国家支援級の攻撃者が、使った: 研究デモや紅白演習ではなく、実在の被害（サプライチェーン侵害・大規模サインイン試行）に結びついた実戦使用が公報された
  2. ツールがOSSだった: 誰でも入手・改変できた状態で実戦投入された（現在は元リポジトリ消失・フォークが残存）
  3. 「偵察→列挙→認証試行→悪用」の多段工程をAIが自律連鎖できる枠組みが、攻撃者の実用装備になった

💡 Tip: 防御側の視点で一番肝心なのは「攻撃が速く・疲れず・適応的になった」という性質の変化です。人間のペネトレーションテスターが夜寝る時間帯にも、AI駆動の攻撃は走り続けます。第2章「防御側教訓」はこの前提から始まります。

誰にとっての話か

ARTEX の作者規約は「個人学習・ローカル検証のみ・実在オンラインシステムへの実テスト禁止」でした。つまり攻撃ツールそのものを個人開発者が触る用途はありません。しかし、事件から得られる防御側の教訓は個人開発者にこそ刺さります。

  • 大企業には WAF・SIEM・セキュリティ専門チームがあります
  • 個人開発のアプリには、ほとんど何もありません
  • そして攻撃者は「守りが薄い方」を探しています

本ガイドは Microsoft 報道レベルの事実参照だけに留めて事件を整理し（攻撃手順の再現は一切扱いません）、その防御側教訓を個人開発のアプリに実際に適用したらどうなったかの実録として記録します。

注意: 本ガイドは攻撃ツールの機能解説・セットアップ手順・攻撃の再現を含みません。すべての記述は防御（検知・ハードニング）の視点に限定しています。
